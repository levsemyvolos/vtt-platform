Нотатки до рішень — гібридний concept

17 точок рішення. Для кожної: оціни своє ставлення (skip / softer / take Ash / take Midnight / take both) і запиши вільні нотатки. Усе зберігається в localStorage. Коли все заповниш — натисни Export, щоб згенерувати гібридний concept.

Типографіка та текст
01 · Шрифт заголовків

Display-серіф для h1/h2

Зараз — Inter Bold. Альтернативи: EB Garamond (Ash, важчий, "пам'ятниковий"), Cormorant Garamond (Midnight, повітряний, ритуальний). Softer = серіф тільки на Landing/Auth, у Dashboard залишити Inter.
Поточний: Inter 700 Ash: EB Garamond 500 Midnight: Cormorant 500
02 · Italic-акцент у заголовку

Виділення ключового слова курсивом + кольором

Обернути одне слово в <em> — стає italic + gold/ember. Ash робить це рідко (ember-only-on-rare-moments), Midnight — щедро. Softer = тільки на сторінках Landing/Auth, не в Dashboard.
Ash em color: #d36418 (ember) Midnight em color: #c9a35a (gold)
03 · Eyebrow style

Стиль mini-label над заголовками

Зараз — Inter 600 11px letter-spacing:0.15em, mute color. Альтернативи: Ash mono 10px 0.42em + 24px риска, муто. Midnight mono 10px 0.32em + риска, gold. Softer = додати риску, але tracking лишити 0.15em.
Поточний: 0.15em mute Ash: 0.42em bone, дуже широке Midnight: 0.32em gold + риска
Палітра та кольори
04 · Базова палітра bg/surface

Глибина чорного / тепло пергаменту

Зараз dark #0f1117 (синюватий) + light #f4f2ec (тепла кремова). Ash жорсткіший: dark #050507 + light #f0e8d4. Midnight тепліший: dark #0a0809 + light #f3ead6. Softer = змінити лише dark на тепліший #0a0809, light залишити.
поточний bg Ash Midnight
05 · Додавання --color-ember

Третій сигнальний колір (ember)

У проекті немає ember взагалі. Додати --color-ember для активного ходу / AI-generation in progress / critical actions. Ash: #d36418 (рідкісний). Midnight: #d6552a (повсякденний у halo+CTA). Softer = додати, але вживати лише на одному місці (як Ash).
Ash ember: Midnight ember:
06 · Додавання --color-rune

Окремий колір для magic glyphs

У Midnight окремий --rune (#f6caa0 dark / #6a4a0e light) — для AI-generated icons, spell symbols, magic items. У проекті немає. Ash не виділяє. Чи потрібно?
07 · Золотий градієнт замість плоского primary

--color-primary як 2-stop gradient

Поточний primary — flat #c8a24a/#8c6e2a. Midnight робить його gradient --gold-bright → --gold (#f0d089 → #c9a35a) для CTA-кнопок. Дрібниця, але кардинально змінює відчуття "натиснутості". Softer = тільки на Hero CTA, не на всіх primary buttons.
08 · Правило "Wound red"

Розвести danger на UI vs HP

Зараз --color-danger вживається і на destructive-кнопках, і на HP. Ash вимагає розвести: blood (#b22a1c) — лише HP/wound; destructive button — gold outline. Softer = додати окремий --color-wound, але danger button лишити червоним.
Геометрія та форми
09 · Border radius

Округлені кути / квадратні

Зараз: 8/12/9999px (mix). Ash жорстко забороняє радіуси (всюди 0). Midnight активно змішує — sigil 50%, pill 999px, cards 4px. Softer = зменшити до 4/2/9999px (тонше скругление, але не square).
Поточний: 4/8/12/9999 Ash: 0 всюди Midnight: 4/50%/999
10 · Sigil-логотип (медальйон)

Замінити квадратний Logo на круглий медальйон

Унікально для Midnight: 4-layer CSS construct (radial-metal + engrave + inner ring + glowing rune). У Ash брендування текстове, без sigil. Softer = залишити квадратний Logo, але додати inset shadow + glow на літеру.
Тіні, halo, фон
11 · Engraved shadows

Inset-тіні на input/button/panel

Зараз — простий box-shadow на cards. Концепти додають "engrave": inset 0 1px gold-rim + inset 0 -1px чорна основа = відчуття "вирізаності з металу". Ash більш чорний (rgba(0,0,0,.6)), Midnight — теплий (rgba(255,220,160,.05)).
12 · Halo glow на CTA

3-layer glow (Midnight only)

Унікально для Midnight: --halo = 1px gold rim + 28px ember diffusion + 60px gold aureole. Сильно змінює відчуття primary CTA. Ash немає. Softer = halo тільки на Hero CTA лендінгу, не на всіх кнопках.
13 · Атмосферний фон body

Текстура замість плоского bg

Зараз body — один колір. Ash: heavy SVG-grain (opacity 0.55). Midnight: 5-layer (radial gradients + 115° hatching + grain dots, opacity 0.35). Softer = тільки на Landing/Auth, інші сторінки залишити плоскими (продуктивність + читабельність).
Ash grain: heavy 0.55 Midnight: light 0.35 + 5 шарів
Компоненти та правила
14 · Правило "Ember on the active hour"

Активний хід в Initiative — інший колір

Зараз активний токен в Initiative — той самий gold що й primary. Ash: ember (інакший) + ember-dot. Покращує читабельність "хто зараз ходить". Не потребує нового компонента — лише умовний клас.
15 · Pulse-dot бейджі

Анімований індикатор LIVE / DANGER

Унікально для Midnight: @keyframes pulseDot 1.6s ease-in-out (opacity 1→.55 + scale 1→.85). Для WebRTC LIVE, low HP, AI generation in progress. Поточний проект має статичні pill-badges. Softer = залишити статичний badge, але додати glow на dot без анімації.
16 · Ping-meter (4-bar)

Візуальний індикатор пінгу WebRTC

Зараз — лише число "42 ms". Midnight додає 4-bar (5/8/11/14px), читається миттєво. У Ash немає. Дрібний компонент, окремо в топбарі.
17 · Theme toggle компонент

Pill (round) vs Dial (square)

Зараз — pill 9999px з flat fill. Ash: square dial з ember-підкресленням (унікальне). Midnight: pill з gold gradient + halo (модернізація поточного). Назви: "Темна/Світла" → "Ash/Dawn" або "Midnight/Sacred Dawn".
18 · ::selection золотий

Перевизначити highlight кольору тексту

Дефолт — браузерний синій. Midnight: ::selection {background:gold; color:bg-0}. Дрібниця, помітна при читанні AI-описів сцен/чату. 1 правило CSS. Ash не виділяє.
Унікальні блоки одного концепту
19 · "The 4 Words" manifest (Ash only)

Блок-маніфест на Landing замість features-grid

Унікально для Ash: 4 курсивні слова-цінності через тонкі sepia-розділювачі. Альтернатива стандартному "features" блоку. Підходить для першого екрану публічної сторінки. Можна не брати концепцію тем, а лише цей блок.
20 · Назви тем

"Темна/Світла" / "Ash/Dawn" / "Midnight/Sacred Dawn"

Поточне — нейтральне функціональне. Концепти переводять у метафору: Ash → "час дня" (ніч/світанок), Midnight → "ритуал/священне". Softer = українські поетичні назви, не запозичувати англомовні концептів дослівно.
Загальні нотатки до гібриду
∞ · Free-form

Що ще турбує / куди тягне / що боюсь зламати

Тут можна писати все що не потрапило у конкретні пункти: пропорції, terminology, обмеження дедлайну, UX-острахи, посилання на Bible-розділи, додаткові концепти.
