### 1.5 Cold start UX

- **На localhost:** BootstrapLoader не відображається — bootstrap занадто швидкий (<100 ms).
- **Код існує:** `BootstrapLoader.tsx` — 4 стадії:
  - 0–3 с → спінер
  - 3–15 с → "Connecting to server..."
  - 15–45 с → "Server is waking up..."
  - 45+ с → кнопка "Retry"
- **Інтеграція:** в `App.tsx` рядок 149-150 — `{status === 'bootstrapping' || status === 'error' || inviteJoining ? <BootstrapLoader ... /> : ...}`.
- **Висновок:** ❓ Не можна верифікувати на localhost. Треба тест на Render/production де cold start реальний.

## Логотип — root cause

Wave 5.6 інструкція агенту була: "Створи стилізований D20 з літерами VTT в центрі". Агент створив pentagon mark — проблема в тому, що Roll20 теж використовує **pentagon-shaped D20-icon** як свій логотип. Геометрична схожість — пряма.

Варіанти редизайну:
1. **Інша геометрія кубика** — d4 (тетраедр), d8 (октаедр), або d6 (звичайний cube). Менш "пентагонально-Roll20".
2. **Сюжетний знак** — wireframe-style 3D-кубик з номерами на гранях, або кубик у руці, або wave-like абстракція.
3. **Чисто типографський** — `VTT` set у геральдичному / fantasy-шрифті без icon (як у Linear, Vercel — текст-only).
4. **Меч + кубик** — комбінація RPG-атрибутів, типу d6 з мечем поверх.

Рекомендую **Варіант 3 (типографічний)** — найбезпечніший, найшвидший, не лишає простору для plagiarism, виглядає professionally. Або **Варіант 1 з d4/d8** — теж безпечно.

Favicon — окремий artefact: `apps/client/public/favicon.svg` або `index.html` — треба замінити Vite-default на новий логотип.
