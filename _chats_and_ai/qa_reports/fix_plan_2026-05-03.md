## 1.1 — Server-side input validation (закриває BUG-004 + MIN-008)

**Сформулюй проблему:**  
Жоден ендпоінт не має zod-валідації input length. Наслідок — 500 на довгих іменах, потенційні XSS-вектори, незрозумілі повідомлення помилок.

### Кроки
1. **Встановити zod** (якщо ще немає):
   - `apps/server/package.json` → переконатись що `zod` у dependencies.
2. **Створити middleware** `apps/server/src/middleware/validate.ts`:
   ```ts
   export function validate<T extends ZodSchema>(schema: T) {
     return (req, res, next) => {
       const result = schema.safeParse(req.body);
       if (!result.success) {
         return res.status(400).json({
           code: 'VALIDATION_FAILED',
           message: 'Invalid request body',
           issues: result.error.flatten(),
         });
       }
       req.body = result.data;
       next();
     };
   }
   ```
3. **Створити schemas** `apps/server/src/schemas/`:
   - `room.schema.ts` — `roomCreateSchema`, `roomUpdateSchema` (name 1–100, system 0–50)
   - `scene.schema.ts` — `sceneCreateSchema` (name 1–100)
   - `token.schema.ts`
   - `character.schema.ts`
   - `note.schema.ts`
   - `handout.schema.ts`
   - `chat.schema.ts` (content 1–2000)
4. **Підключити validate()** до кожного POST/PATCH ендпоінта в `apps/server/src/routes/*.ts`.
5. **На клієнті:** створити обгортку `<TextField maxLength={N} showCounter />` в `apps/client/src/components/ui/`.

## 1.2 — RBAC: Observer-token scope (закриває BUG-003)

**Сформулюй проблему:**  
Observer JWT не має поля `role`/`scope`. Анонімний user проходить як звичайний на всіх ендпоінтах. Можна створювати кімнати, бачити My Rooms.

### Кроки
1. **Розширити JWT payload** в `apps/server/src/services/authService.ts`:
   ```ts
   interface AccessTokenPayload {
     sub: string;
     email: string;
     name: string;
     role: 'user' | 'observer';        // ← NEW
     boundRoomId?: string;              // ← NEW (тільки для observer)
     iat: number;
     exp: number;
   }
   ```
2. **`issueObserverTokens()`** ставити `role: 'observer'` + `boundRoomId: room.id`.
3. **Створити middleware** `apps/server/src/middleware/requireRole.ts`:
   ```ts
   export const requireRole = (allowed: Array<'user' | 'observer'>) => 
     (req, res, next) => {
       if (!req.user || !allowed.includes(req.user.role)) {
         return res.status(403).json({ code: 'FORBIDDEN' });
       }
       next();
     };
   ```
4. **Підключити `requireRole(['user'])`** до:
   - `POST /api/rooms` (create room)
   - `GET /api/rooms?filter=owned|invited` (My Rooms list)
   - всіх PATCH/DELETE рум
5. **Підключити `requireRole(['observer', 'user'])`** + перевірку `req.user.boundRoomId === req.params.id` до observer-доступних ендпоінтів.
6. **На клієнті:**
   - `store/session.ts` зберегти `currentUser.role` та `currentUser.boundRoomId`.
   - `App.tsx`: якщо `role === 'observer'` → ніколи не показувати Dashboard, тримати на GameRoom тієї однієї кімнати; logout = clear token.
   - Сховати в Sidebar / Header опції недоступні Observer (Create Room, My Rooms, Settings, etc.).

## 2.1 — Player invite via `?invite=TOKEN` (закриває BUG-001)

**Сформулюй проблему:**

2. `roomService.joinByInvite()` (або repo нижче) можливо не пише membership.
3. URL очищається ДО підтвердження — F5 ламає flow.

### Кроки
1. **Перевірити серверний `joinByInvite`** (`apps/server/src/services/roomService.ts`):
   - Чи створює `RoomMember` запис?
   - Чи додає user в проекцію `getMembersProjection()`?
   - Якщо ні — додати `await memberRepo.create({ roomId, userId, role: 'player' })`.
2. **Сервер: повертати оновлений RoomDTO** з members що включає поточного user.
3. **Сервер: емитити WS-подію** `room:member-joined` для GM-вікна (real-time оновлення Lobby).
4. **App.tsx — переписати invite handler:**
   ```ts
   useEffect(() => {
     if (status !== 'authenticated' || currentRoom) return;
     const params = new URLSearchParams(window.location.search);
     const invite = params.get('invite');
     if (!invite) return;
     
     dispatch(setInviteJoining(true));  // блокує редіректи
     apiFetch<RoomDTO>('/api/rooms/join', {
       method: 'POST',
       body: JSON.stringify({ token: invite }),
     })
       .then((room) => {
         dispatch(setCurrentRoom(room));
         window.history.replaceState({}, '', window.location.pathname);
         showToast({ type: 'success', text: t('room:invite.joined', { name: room.name }) });
       })
       .catch((err) => {
         showToast({ type: 'error', text: t('errors:invite.failed') });
         // НЕ очищати ?invite — залишити щоб user міг побачити що сталось
       })
       .finally(() => dispatch(setInviteJoining(false)));
   }, [status]);
   ```
5. **Lobby (GM-side):** підписатися на WS `room:member-joined` → оновити список Members без F5.
6. **i18n:** додати ключі `room:invite.joined`, `errors:invite.failed`, `errors:invite.expired`.
